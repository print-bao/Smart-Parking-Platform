# Work Breakdown Structure & Timeline
## Work Breakdown Strcture (WBS) for Parking App 
This WBS divides the Smart Parking PLatform into smaller components to assist with organizing the project's scope, features, and deliverables.

### 1.0 Smart Parking Platform
#### 1.1 Authentication
- 1.1.1 Driver Registration
- 1.1.2 Operator Registration
- 1.1.3 Login and Session Management
- 1.1.4 Password Reset
#### 1.2 User and Operator Setup
- 1.2.1 Driver Profile
- 1.2.2 Operator Profile
- 1.2.3 Account Management
#### 1.3 Garage Monitoring
- 1.3.1 Garage Management
- 1.3.2 Garage Availability
- 1.3.3 Garage Occupancy
#### 1.4 Payment
- 1.4.1 Checkout Page
- 1.4.2 Payment Processing
- 1.4.3 Payment Receipt
#### 1.5 Reporting
- 1.5.1 Occupancy Report
- 1.5.2 Financial Report
- 1.5.3 Payment History
- 1.5.4 Reservation History
